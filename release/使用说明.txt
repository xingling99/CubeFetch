CubeFetch（方块速递）v1.2.1-beta 使用说明
========================================

一、这是什么
  一个 Windows 桌面版 Minecraft Java 版下载器。用 Microsoft 正版账号登录后，
  按「正式版 / 预览版 / 远古版 / 愚人节版」选择游戏版本，可选 Fabric / Quilt /
  Forge / NeoForge 模组加载器，多线程下载游戏本体与资源，并自动写好 PCL2/HMCL
  的版本隔离配置。

  本版本（v1.2.1-beta）主要变化：
  - 检测到游戏目录后启动即自动选中（版本数最多的目录），不再弹窗要求手动选择；
    设置页的「自动检测」也会直接选中并保存，「浏览…」仍可手动更换目录；
  - 界面整体重写为「深色现代极简」风格：近黑背景、大圆角卡片、1px 细边线、
    紫青渐变强调色、胶囊式导航与分类标签、大留白排版；弹窗也改为自绘现代样式；
  - 点「登录」后自动打开浏览器，并把设备验证码自动复制到剪贴板，直接粘贴即可；
  - DPI 缩放：在 125% / 150% 缩放屏下字体与布局清晰，不再模糊错位；
  - 「自动检测」改为扫描各启动器 .minecraft\versions 下的已安装版本，设置页会显示
    「目录（N 个版本）」，即使启动器配置丢失也能找到游戏目录；
  - 进度显示更准确：百分比、总大小、文件进度、当前阶段分行显示，不再出现数字打架；
  - 文件级完整性校验：程序文件被改动时会提示并禁止下载；
  - 打开「下载」页自动拉取最新版本清单并刷新列表；
  - 下载前检测 Java：没有合适的 Java 时会弹窗询问，是否一并下载官方 Java 运行时
    （默认装到 .minecraft\runtime，约 95 MB）；
  - 若目标版本已存在，可当场输入一个新的版本名（自动重命名）；
  - 所有提示带提醒音效；有任务进行中关闭窗口会先弹窗确认。

二、运行环境
  - Windows 10 / 11（64 位）
  - 拥有 Minecraft Java 版的 Microsoft 账号
  - 安装 Forge / NeoForge 需要 Java：程序会自动探测本机 Java；没有时可在下载时
    选择一起下载官方 Java 运行时，也可在设置里手动指定 java.exe
  - 运行库已全部打进 exe，无需安装 Python

三、快速开始
  1. 双击 CubeFetch.exe。
     （exe 没有代码签名，Windows SmartScreen 可能提示：点「更多信息 → 仍要运行」。）
  2. 点「使用 Microsoft 账号登录」：
     程序会自动打开浏览器 https://www.microsoft.com/link，窗口里显示的设备码也已自动
     复制到剪贴板，直接在浏览器里粘贴即可，按提示完成登录授权，回到 CubeFetch。
     账号凭据用 Windows DPAPI 加密保存在本机，默认 30 天内免登录；
     超过 30 天会要求重新验证；在设置页可以退出登录。
  3. 「设置」里确认 .minecraft 目录（启动时已自动选中版本数最多的目录，如
     D:\pcl2\.minecraft（3 个版本）；想更换可点「自动检测」或「浏览…」）、
     下载源（默认「自动（优先镜像）」，即优先走 BMCLAPI 镜像、失败再回落官方源）、
     下载线程数（默认 32）。
  4. 「下载」页：左侧选正式版/预览版/远古版/愚人节版分类，选中游戏版本；右侧选加载器
     （原版 / Fabric / Quilt / Forge / NeoForge，加载器版本会自动推荐最新），点「开始下载」。
     - 如果本机没有该版本合适的 Java，会弹窗询问是否一起下载官方 Java 运行时；
     - 如果该版本已经装过，会弹窗让你输入一个新的版本名（留空则使用现有版本）。
     进度页可看多线程下载速度与总进度，可取消。
  5. 完成后会自动把该版本设为「版本隔离」，PCL2 直接就能在版本列表里看到并启动；
     HMCL 也会写入对应隔离配置。

四、下载数据放在哪里
  - 程序配置/账号/日志：%LOCALAPPDATA%\CubeFetch\
      config.json    设置
      account.dat    DPAPI 加密的账号（30 天记忆）
      logs\cubefetch.log  运行日志（出问题先看这里）
  - 游戏文件：你设置的那个 .minecraft 目录（libraries / assets / versions）
  - Windows 版 Java 运行时（若选择随游戏一起下载）：.minecraft\runtime\

五、常见问题
  - 提示没有正版 / 登录失败：确认该 Microsoft 账号已在 Xbox 与 Minecraft 中完成设置，
    并且确实拥有 Java 版；错误码会在界面上给出中文说明。
  - Forge / NeoForge 首次安装比较慢（约 2-3 分钟）：安装器要下载并执行补丁处理器，
    属正常现象，进度页会显示阶段文字，可重试，已下载的文件会复用。
  - 网络慢 / 下载失败：设置里把下载源改成「自动」（默认）或「BMCLAPI 镜像」，
    程序本身也支持官方源失败后自动切镜像、断点续传。
  - 界面字体模糊 / 窗口偏小：本版本已支持高 DPI 缩放；若仍异常，可在启动前设置
    环境变量 CUBEFETCH_DPI_SCALE=1.5（数值按你的缩放比例）强制指定。
  - 进度页数字含义：「文件进度」是整体已完成/总数；「本阶段」是当前阶段内部进度；
    百分比按已下载字节计算，静态文件阶段结束后会进入资源文件阶段，属正常流程。
  - 杀毒软件误报：PyInstaller 打包的单文件 exe 偶尔被误判，可加入白名单；
    源码在开源仓库，可自行构建（build\build.ps1）。
  - 关于完整性校验：这是提高破解门槛的自检，不是绝对防护；请勿手动修改程序目录内
    的文件，否则会被判定为文件被篡改并禁止下载。源码自行构建时，打包脚本会自动生成
    与代码匹配的校验清单。
  - 想改界面/功能：源码与文档在项目目录；模块接口见 docs\CONTRACTS.md。
